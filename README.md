# SuperStore Sales Performance & Multi-Page BI Analytics Dashboard

**Role:** BI & Data Analyst

## 📌 System Scope
Executed an end-to-end retail sales analysis across **three weekly phases** (data preprocessing, decision-maker analytical questioning, and interactive dashboarding) to evaluate revenue growth, customer repeat behavior, regional and category performance, and product revenue concentration.

## 🛠️ Technical Implementation
- Cleaned and prepared the dataset in **Power BI** and formulated targeted business intelligence questions.
- Engineered a **3-page interactive dashboard** (**Executive Overview**, **Sales Analysis**, and **Product Analysis**) featuring:
  - Dynamic slicers (`Year`, `Region`, `Category`, `Segment`)
  - Core KPIs (`Total Sales`, `Repeat Rate %`, `Total Orders`, `Total Customers`, `Avg Order Value`, `YoY Sales Growth`, `Sales YTD`, `Top 10% Revenue Share`)
  - Monthly, quarterly, and day-of-week trends alongside regional, segment breakdowns, and top-product ranking visuals

## 🧩 Tech Stack
- **Microsoft Power BI**
- **Data Preprocessing**
- **DAX & KPI Engineering**
- **Data Visualization**
- **Interactive Slicers**
- **Exploratory Data Analysis**
